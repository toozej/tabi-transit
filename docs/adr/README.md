# Architecture decision records

This directory contains Tabi architecture decision records (ADRs). An ADR is authoritative only when its status is **Accepted**. Accepted ADRs supersede implementation-plan guidance when they conflict.

Use [0000-template.md](0000-template.md) for new records. Decisions that need a device test, provider terms, credentials, cost evidence, or an operator choice remain **Proposed** or **Deferred** and are listed in the [architecture decision register](../architecture-decision-register.md).
